# Knock

| Level    | [2nd Level Spell](2nd%20Level%20Spells.md)                            |
| -------- | --------------------------------------------------------------------- |
| Casting  | 1 [Action](../../../../Game%20Procedures/Core%20Procedures/Action.md) |
| Duration | None                                                                  |
| Range    | Touch                                                                 |

Choose an object that you can see within range. The object can be a door, a chest, manacles, a padlock, or another object that contains a mundane or magical means that prevents access.

A target that is held shut by a mundane lock or that is stuck or barred becomes unlocked, unstuck, or unbarred. If the object has multiple locks, only one of them is unlocked.

If the target is held shut by [Arcane Lock](Arcane%20Lock.md) or hold [Portal](../Level%205/Portal.md), that spell is dispelled if this spell was cast at a higher level than the target spell.

This creates a thunderous 'knock' audible for hundreds of feet.

---
*Upcast: Defeats higher level target spells.*
