# Hold Object

| Level    | [2nd Level Spell](2nd%20Level%20Spells.md)                            |
| -------- | --------------------------------------------------------------------- |
| Casting  | 1 [Action](../../../../Game%20Procedures/Core%20Procedures/Action.md) |
| Duration | Until dispelled ([Concentration](../../Concentration.md))             |
| Range    | 1 [Zone](../../../../Game%20Procedures/Core%20Procedures/Zone.md)     |

You choose an object no bigger than a chest you can see within range for the duration.

The object is magically held in its current location. It can support up to 5,000 pounds of weight for the duration.

---
*Upcast: Supports an additional 5,000 pounds per spell level.*
