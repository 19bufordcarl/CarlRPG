# 5e Chardenfell Introduction

This set of homebrew options provides tools for players and GMs to immerse themselves in the fantasy world of Chardenfell dominated by massive volcanoes and mushroom forests.

This game assumes you are using the SRD 5.2 or similarly compatible version of 5e as a basis for your game rules, while this set of rules provides alternative rules for character creation to better fit the land of Chardenfell.

## Inspiration

This project takes heavy inspiration from the Lazy DMG by Mike Shea, and follow many of his philosophies for running RPGs.
