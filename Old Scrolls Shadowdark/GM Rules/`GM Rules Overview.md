# GM Rules Overview

These are rules classically spelled out in the GM's Rule Book rather the Player's Rule Book in system rules. There are many options and flexibilities provided, and this document details which options best fit the world of Chardenfell as the author would run it.

## Shadow-Lite

I will not use the strict 1 hour timers and 'no darkvision' rules that is presented in the book. Expect a little bit cozier and higher fantasy than default Shadowdark. I like the rules for their simplicity.

## Death Saves

No more unconscious jail time. Now, these represent your true bodily health. See [Death Saves](Death%20Saves.md).

## Expanded Player Options

See [Ancestries](../Player%20Characters/Ancestry/'Ancestries.md), 

## Economy

Silver piece standard, limited magical item trade, more options for crafting. See [Economy](../../ChardenfellRPG/5e%20Chardenfell/GM%20Rules/Economy.md).

## Experience Points

Award XP points per session, level up at 10 XP then reset back to 0. In narrative power sources required to go past level 6. See [Experience Points](../../ChardenfellRPG/5e%20Chardenfell/GM%20Rules/Experience%20Points.md).

### Resting

Resting is no longer free. You lose 1 XP per long rest you take.
