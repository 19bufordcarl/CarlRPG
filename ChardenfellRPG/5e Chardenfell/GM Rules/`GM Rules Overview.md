# GM Rules Overview

These are rules classically spelled out in the GM's Rule Book rather the Player's Rule Book in the "5.2 SRD" rules and similar systems. There are many options and flexibilities provided, and this document details which options best fit the world of Chardenfell as the author would run it.

## Combat Clarifications

Modified initiative, surprise, and more monster tactical options. See [Combat Clarifications](Combat%20Clarifications.md).

## Death Saves

No more unconscious jail time. Now, these represent your true bodily health. See [Death Saves](Death%20Saves.md).

## Expanded Player Options

See [Species](../Player%20Options/Species/Species.md), [Crafting](../Player%20Options/Magic/Crafting.md), and [Classes](../Player%20Options/Classes/Classes.md) for more details!

## Economy

Silver piece standard, limited magical item trade, more options for crafting. See [Economy](Economy.md).

## Experience Points

Award XP points per session, level up at 10 XP then reset back to 0. In narrative power sources required to go past level 6. See [Experience Points](Experience%20Points.md).

### Resting

Resting is no longer free. You lose 1 XP per long rest you take.
