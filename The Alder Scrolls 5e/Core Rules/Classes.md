# Classes

## Character Class

Each character class has the following key elements.

### Primary Ability

Each class has a core ability that defines its features. When in doubt, make this your highest ability.

### Hit Points

Your class determines the die you roll for hit points. You add your Constitution modifier to the roll. At level 1, you start with the maximum hit points you could roll. When you gain a level, you can roll or treat the die roll as half the maximum you could roll (rounded down).

### Proficiencies

Your class grants you saving throw and weapon proficiencies.

### Expertise

If you choose proficiency in a skill that you are already proficient with, you gain expertise with it instead.

### Starting Equipment

The class includes a starting gear bundle. You can swap items as you wish. You can exchange your armor for any cheaper set of armor. You can exchange your weapons for any other nonmagical weapons that are cheaper.

### Quick Start Abilities

Instead of rolling abilities, you can use the array provided by the character class.
